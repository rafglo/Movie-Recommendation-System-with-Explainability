# App Screenshots

The Streamlit app can be captured after starting it with:

```powershell
python -m streamlit run app.py
```

Recommended screenshots for the final report or presentation:

1. User recommendation view after clicking `Generate Recommendations`.
2. Expanded `Contribution details` panel showing component and SHAP values.
3. Similar-movies view after searching for `Matrix`.

The in-app browser automation was unavailable in this environment, and a
whole-screen Windows screenshot was avoided because it could capture unrelated
desktop content. Capture app-only screenshots manually from the browser window
or with a dedicated browser screenshot tool.
